## 统一结构

每单元均含：单元导读 → 知识点精讲 → 42 词核心词汇表 → 全英文原创仿题 → 指示性答案与解析 → 自学检查清单。

## 题量

0455：72 题；9708：116 题；合计 **188 题**。题号 Q1–Q188 连续且不重复。

## 建议用法

1. 预习只读导读、术语和精讲标题，写下三个问题。
2. 精学时重画图表并口头复述因果链。
3. 限时完成练习后，按 AO1（知识）、AO2（应用）、AO3（分析）、AO4（评价）四色订正。
4. 答案是“可得分路线”，不是唯一措辞；先作答再查看。
