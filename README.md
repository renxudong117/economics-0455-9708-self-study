## 统一结构

每单元均含：单元导读 → 知识点精讲 → 按本单元负担设置的核心词汇表 → 原创/重新设定情境的 Cambridge-style 练习 → 明确答案与解析 → 自学检查清单。

## 题量

0455：72 题；9708：116 题；合计 **188 题**。题号 Q1–Q188 连续且不重复。

## 建议用法

1. 预习只读导读、术语和精讲标题，写下三个问题。
2. 精学时重画图表并口头复述因果链。
3. 限时完成练习后，按 0455 的 AO1（知识与理解）、AO2（分析）和 AO3（评价）检查失分原因。
4. 答案是“可得分路线”，不是唯一措辞；先作答再查看。
