# Repository instructions for courseware work

Before creating, regenerating, extending or reviewing any courseware in this repository, read `COURSEWARE-STANDARD.md` in full and apply its latest version as the default specification. Version 2.0 section 0 is the overriding baseline when older experience entries conflict.

The standard is mandatory for the official-unit six-part structure, systematic bilingual explanations, numbered knowledge points, rich unit practice, explicit matching answers, diagram placement, printable files and QA. Do not revert to the older lesson-level five-part structure unless the user explicitly requests it. A user's latest explicit instruction takes priority.

After implementing reusable user feedback, update `COURSEWARE-STANDARD.md`, raise its version when appropriate, and append a dated entry under “经验记录”. Keep the standard and the generated artifacts in the same Git commit whenever practical.
