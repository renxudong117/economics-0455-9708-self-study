# Repository instructions for courseware work

Before creating, regenerating, extending or reviewing any courseware in this repository, read `COURSEWARE-STANDARD.md` in full and apply its latest version as the default specification.

The standard is mandatory for lesson structure, bilingual explanations, numbered knowledge points, exam workshops, explicit answers, diagram placement, printable files and QA. A user's latest explicit instruction takes priority.

After implementing reusable user feedback, update `COURSEWARE-STANDARD.md`, raise its version when appropriate, and append a dated entry under “经验记录”. Keep the standard and the generated artifacts in the same Git commit whenever practical.
