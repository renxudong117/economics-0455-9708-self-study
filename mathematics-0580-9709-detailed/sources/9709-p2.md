## 第 1 课｜代数与模函数｜Algebra and modulus

### 概念拆解

|x|是到0的距离，分段线性；方程|f(x)|=a需考虑正负两支。

### 方法推导

先定位零点分段，或用几何交点；平方前确认不会引入增根。

### 例题一

解 |2x−3|=7。

**解：** 2x−3=7或−7，得x=5或−2。

### Cambridge-style application

Solve |x+1|<4.

**Solution:** −4<x+1<4, hence −5<x<3.

Define or identify → model → calculate with visible steps → interpret → check.

## 第 2 课｜指数与对数｜Exponentials and logarithms

### 概念拆解

对数是指数的逆运算；log laws 只适用于乘积、商和幂。

### 方法推导

先统一底数或两边取对数；解后检查真数大于0。

### 例题一

解 3^(2x−1)=20。

**解：** 2x−1=ln20/ln3，所以x=[1+ln20/ln3]/2≈1.863。

### Cambridge-style application

Solve ln(x−1)+ln(x+1)=ln8.

**Solution:** ln(x²−1)=ln8, so x²=9. Domain x>1 gives x=3.

Define or identify → model → calculate with visible steps → interpret → check.

## 第 3 课｜三角恒等与方程｜Trigonometric identities

### 概念拆解

恒等式对定义域内所有值成立；方程只对某些值成立。

### 方法推导

优先把式子化成同一种函数，使用sin²x+cos²x=1和tanx=sinx/cosx。

### 例题一

证明 (1−cos²x)/sinx=sinx。

**解：** 1−cos²x=sin²x，所以左边=sin²x/sinx=sinx（sinx≠0处；原式也要求分母非零）。

### Cambridge-style application

Solve 2cos²x−3cosx+1=0 for 0≤x≤2π.

**Solution:** (2cosx−1)(cosx−1)=0; x=π/3,5π/3,0,2π.

### Exam method

Define or identify → model → calculate with visible steps → interpret → check.

## 第 4 课｜微分法则与应用｜Differentiation applications

### 概念拆解

链式、乘积和商法则处理复合表达式；导数模型可给速度、最优化和近似。

### 方法推导

先识别外函数与内函数；优化题写目标函数、定义域、驻点与验证。

### 例题一

微分 y=(3x−1)^5。

**解：** dy/dx=5(3x−1)^4×3=15(3x−1)^4。

### Cambridge-style application

A rectangle has perimeter 40. Maximise its area.

**Solution:** Let sides x and 20−x. A=20x−x²; A′=20−2x=0 gives x=10, and A″<0, so max area 100.

### Exam method

Define or identify → model → calculate with visible steps → interpret → check.

## 第 5 课｜积分与面积｜Integration applications

### 概念拆解

定积分可求曲线与轴或两曲线间面积；上减下并关注交点。

### 方法推导

先解交点决定上下关系；含(ax+b)^n可反链式积分。

### 例题一

求∫(2x+1)^4 dx。

**解：** (2x+1)^5/10+C。

### Cambridge-style application

Find area between y=x and y=x² from 0 to 1.

**Solution:** ∫₀¹(x−x²)dx=[x²/2−x³/3]₀¹=1/6.

## 第 6 课｜数值解法｜Numerical solution

### 概念拆解

迭代法用x_{n+1}=g(x_n)逼近根；收敛并非自动保证。

### 方法推导

按给定公式逐次计算，报告所需精度；用区间符号变化验证根。

### 例题一

x_{n+1}=√(2x_n+3)，x₁=2，求x₄。

**解：** x₂=√7≈2.6458，x₃≈2.8795，x₄≈2.958。

### Cambridge-style application

Explain how to show a root lies in (a,b).

**Solution:** For continuous f, calculate f(a) and f(b). Opposite signs imply at least one root in the interval.

## 第 7 课｜P2 综合题｜P2 synthesis

### 概念拆解

P2 要求更成熟的代数转换，特别是精确值、定义域和逆向验证。

### 方法推导

每次变形记录依据；含log、root、denominator时做限制检查。

### 例题一

求曲线y=lnx在x=e处的法线。

**解：** 点(e,1)，切线梯度1/e，法线梯度−e；y−1=−e(x−e)。

### Cambridge-style application

Why can squaring create extraneous roots?

**Solution:** Squaring removes sign information, so a value satisfying the squared equation may fail the original equation; substitute back.
