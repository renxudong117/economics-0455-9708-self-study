# Cambridge Mathematics 0580 + 9709 详细学习手册

本目录提供按独立课时编排的中英文学生自学教材。每课采用统一结构：概念拆解、原理推导、可执行步骤、双语例题、Cambridge 风格应用、评分点、英文数学表达与易错辨析。

## 分册

- 0580 Core：完整 Core 基础路径。
- 0580 Extended：包含 Core 基础并增加 Extended 深度专题。
- 9709 P1 / P2 / P3：纯数学分卷。
- 9709 M1：现行 Paper 4 Mechanics。
- 9709 S1：现行 Paper 5 Probability & Statistics 1。
- 9709 S2：现行 Paper 6 Probability & Statistics 2。
- 9709 M2：拓展/旧体系衔接册。**现行 2026–2027 9709 考纲没有独立 M2 试卷**，请勿把本册误当报考组件。

### S1 全册六段式双语学习教材（当前主版本）

S1 最新版以用户提供的物理、化学全册为主要格式参考，按官方 5.1-5.5 五个单元连续编排。每个单元严格采用“单元导读 → 知识点精讲 → 核心词汇表 → 单元练习 → 练习答案与解析 → 自学检查清单”六部分结构。全册 47 页，含 133 个主题词和 81 道全英文原创 Cambridge-style 练习；中文概念拆解后配有成段英文解释，计算题答案展示公式、代入与结论。原 12 课版本继续保留用于比较，本轮未修改 P3 及其他数学分册。

### P3 九单元六段式双语系统教材（当前主版本）

P3 最新版按官方 3.1–3.9 九个主题连续编排，每单元采用“单元导读 → 知识点精讲 → 核心词汇表 → 单元练习 → 练习答案与解析 → 自学检查清单”六部分结构。全册 38 页，含 92 个核心术语和 73 道全英文原创 Cambridge-style 练习；每道题均有同号答案，计算题展示公式选择、代入、化简、检验和最终结论。知识点数量由各单元实际方法决定，不按固定模板凑数。旧 P3 逐课版继续保留供比较。
