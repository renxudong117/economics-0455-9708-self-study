# Cambridge International AS & A Level Mathematics 9709 - P1 + P3｜中英文详细讲义

> 考纲基准：2026-2027 P1 + P3。每章按“概念 → 步骤 → 例子 → 易错点”学习。

## P1-1 Algebra and functions｜P1 代数与函数

### 学习目标

掌握 **quadratics, modulus, inequalities, composite and inverse functions**，并能用清晰英语解释步骤。

### 知识点精讲｜Key idea

二次式先根据题目选 factorising、completing the square 或 quadratic formula。modulus 表示 distance from zero：|x−3|<2 等价于 1<x<5；|x−3|>2 产生两个区间。求 inverse 前先交换 x,y 再解 y，并注意 domain restriction。

### 概念、方法与表达｜Learn it in layers

**概念拆解｜Meaning before manipulation.** P1/P3 的题目常把一个概念嵌在长式子、图像或情境内。第一步是写清变量的定义、允许的 domain 和目标量；第二步才选择公式或定理。**quadratics**、**modulus**、**inequalities** 的关键是知道“何时可用”而非只会套用。答案要让阅卷人看见 reasoning：选择方法的理由、代入和化简的每一步。

**标准解题路径｜A repeatable method.** (1) Rewrite the question in a clean mathematical form；(2) identify structure—factor, substitution, a known identity, a derivative/integral pattern or a geometric condition；(3) work symbolically before using decimals；(4) apply any interval/domain/initial condition；(5) check the result in the original relation。若一步需要除以代数式、取 logarithm、平方或开方，必须同步考虑是否引入或丢失解。

**表达与验证｜Communication earns marks.** 保留 exact values（fractions, surds, π, logarithms）直到题目要求近似；写清答案的 range、unit、radian/degree mode 或 parameter。对 “show that” 题，从题给表达式开始，逐行变形到目标；对建模题，句子说明假设是否合理。最后用 substitution、sign、graph shape 或 limiting behaviour 作快速检查。

### 分步示范｜Worked reasoning

**Question focus.** For f(x)=2x+5, f⁻¹(x)=(x−5)/2.

**Step 1 — Identify.** 写出题目给出的量与待求量；判断 **quadratics** / **modulus** 中哪一个是本题主线。

**Step 2 — Set up.** 先列正确关系式，并用括号保护整体代入；不要把心算跳步当作证明。

**Step 3 — Execute.** 每行只完成一个清晰变形，保留准确形式；若得到多个根/角/区间，逐一与限制条件核对。

**Step 4 — Conclude.** 用一句完整英语或双语结论回答题目，并标出单位、精度或可取范围。

### 高频误区｜Why students lose marks

- 把 **quadratics** 当成孤立公式，而没有先检查其定义、条件或适用范围。
- 过早将数值四舍五入，导致后续计算误差或与 mark scheme 的 exact answer 不符。
- 只给答案不展示结构；考试中 method marks 来自正确的设式、变形与验证。

### Exam checklist｜易错检查

- 写出公式或定义，再代数代入。
- 保留足够精度，按题目要求取舍。
- 检查 domain、unit、sign 与题目所求。

log_a(xy)=log_a x+log_a y，但 log(x+y) 不能拆。ln x 只对 x>0 定义。指数方程可取 natural logs；取 log 前确认两侧正。

### 概念、方法与表达｜Learn it in layers

**概念拆解｜Meaning before manipulation.** P1/P3 的题目常把一个概念嵌在长式子、图像或情境内。第一步是写清变量的定义、允许的 domain 和目标量；第二步才选择公式或定理。**laws**、**e^x**、**ln x** 的关键是知道“何时可用”而非只会套用。答案要让阅卷人看见 reasoning：选择方法的理由、代入和化简的每一步。

**标准解题路径｜A repeatable method.** (1) Rewrite the question in a clean mathematical form；(2) identify structure—factor, substitution, a known identity, a derivative/integral pattern or a geometric condition；(3) work symbolically before using decimals；(4) apply any interval/domain/initial condition；(5) check the result in the original relation。若一步需要除以代数式、取 logarithm、平方或开方，必须同步考虑是否引入或丢失解。

**表达与验证｜Communication earns marks.** 保留 exact values（fractions, surds, π, logarithms）直到题目要求近似；写清答案的 range、unit、radian/degree mode 或 parameter。对 “show that” 题，从题给表达式开始，逐行变形到目标；对建模题，句子说明假设是否合理。最后用 substitution、sign、graph shape 或 limiting behaviour 作快速检查。

### 分步示范｜Worked reasoning

**Question focus.** ln(3x)=ln 3+ln x, not 3ln x.

**Step 1 — Identify.** 写出题目给出的量与待求量；判断 **laws** / **e^x** 中哪一个是本题主线。

**Step 2 — Set up.** 先列正确关系式，并用括号保护整体代入；不要把心算跳步当作证明。

**Step 3 — Execute.** 每行只完成一个清晰变形，保留准确形式；若得到多个根/角/区间，逐一与限制条件核对。

**Step 4 — Conclude.** 用一句完整英语或双语结论回答题目，并标出单位、精度或可取范围。

### 高频误区｜Why students lose marks

- 把 **laws** 当成孤立公式，而没有先检查其定义、条件或适用范围。
- 过早将数值四舍五入，导致后续计算误差或与 mark scheme 的 exact answer 不符。
- 只给答案不展示结构；考试中 method marks 来自正确的设式、变形与验证。

### Exam checklist｜易错检查

- 写出公式或定义，再代数代入。
- 保留足够精度，按题目要求取舍。
- 检查 domain、unit、sign 与题目所求。
